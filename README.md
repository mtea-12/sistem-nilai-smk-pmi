# Sistem Nilai SMK PMI

Buat aplikasi web lengkap bernama “Sistem Penilaian Akademik SMK Muhammadiyah 1 Paguyangan”. Seluruh UI wajib Bahasa Indonesia. Buat desain profesional, responsif, mudah digunakan, bernuansa sekolah formal-modern dengan identitas Muhammadiyah yang elegan. Sediakan halaman masuk dan dashboard role-based yang dapat didemokan: Admin (kelola data siswa, guru, kelas, mata pelajaran, tahun ajaran), Guru (input dan rekap nilai tugas, PTS, PAS), Wali Kelas (rekap kelas dan status nilai), serta Siswa (lihat nilai dan rapor). Sertakan data contoh realistis, tabel dengan pencarian/filter, formulir input nilai, kartu ringkasan, halaman rapor yang rapi dan siap cetak/unduh, navigasi sidebar mobile-friendly. Aktifkan backend/data bila dibutuhkan agar struktur aplikasi siap dikembangkan.
